# Activity Time – Product Improvements & UX Recommendations

## Project Overview

This section showcases my contribution to identifying product improvement opportunities, analysing existing user experiences, and proposing design-based solutions for the Activity Time website.

Beyond functional testing and defect identification, I also review existing user journeys to identify areas where usability, accessibility, visual consistency, and overall user experience can be improved.

For each identified improvement, I document the current behaviour, explain its impact on users, propose a practical solution, and create a reference design to demonstrate how the improved experience could look.

The objective is to make product improvement suggestions more structured, understandable, and actionable for product stakeholders, designers, and developers.

## Objective

To evaluate existing website journeys, identify UX and usability gaps, and provide clear improvement recommendations supported by visual reference designs.

Key objectives include:

- Identify usability issues and friction points across customer and provider journeys.
- Evaluate existing UI layouts, forms, modals, navigation, and interactions.
- Identify accessibility and visual consistency improvements.
- Understand how existing design decisions affect user experience.
- Suggest practical solutions to improve usability and user engagement.
- Create reference designs to visually communicate proposed improvements.
- Maintain a structured record of findings, feedback, priorities, and agreed actions.
- Track improvement progress from initial identification through development and completion.

## Improvement Analysis Framework

I follow a structured approach for documenting and communicating product improvements.

### Step 1 – Current Experience Review

Review the existing website journey and understand how the feature currently behaves.

### Step 2 – Observation & Finding

Identify usability gaps, accessibility concerns, visual inconsistencies, or opportunities to simplify the experience.

### Step 3 – User Impact Analysis

Explain how the identified issue may affect users, including confusion, unnecessary effort, readability, navigation, or journey completion.

### Step 4 – Suggested Improvement

Define a practical recommendation that addresses the identified problem.

### Step 5 – Reference Design

Create a visual representation of the proposed improvement to demonstrate the expected user experience.

### Step 6 – Feedback & Discussion

Record client feedback, designer feedback, and agreed actions separately to maintain clarity during product discussions.

### Step 7 – Progress Tracking

Monitor each improvement through its defined status, from initial identification to completion or deferral.

### Examples of Identified Improvements

**1. Mandatory and Optional Field Identification**

The business registration form does not clearly distinguish mandatory and optional fields.

Proposed improvement:
- Display an asterisk (*) beside mandatory fields.
- Display an "(Optional)" label beside non-mandatory fields.

**2. Account Type Selection**

The account type cards do not clearly communicate that they are clickable.

Proposed improvement:
- Add a visible arrow or Select call-to-action.
- Make the entire card clickable.
- Improve the visual interaction cues.

**3. Accessibility – Text Contrast**

The account type descriptions use light grey text on a white background.

Proposed improvement:
- Use darker text for improved readability.
- Aim for a minimum 4.5:1 contrast ratio for normal text, subject to verification.

**4. Modal Visual Improvement**

The modal logo overlaps its top boundary, while the background navigation remains visually prominent.

Proposed improvement:
- Improve background overlay treatment.
- Adjust logo positioning.
- Reduce unnecessary visual distractions.

**5. Account Type Card Alignment**

The two account type cards have noticeable differences in content spacing.

Proposed improvement:
- Maintain consistent padding and alignment.
- Use consistent CTA positioning.

**6. Signup & Profile Setup Progress Indicator**

Users cannot clearly understand how much of the registration and profile setup journey remains.

Proposed improvement:
- Introduce an overall progress indicator.
- Display step information and completion percentage.
- Show sub-steps within the business profile setup.
- Allow users to resume from their previously saved progress.

**7. Login & Sign Up Modal Improvement**

The current modal does not sufficiently separate the form from the background page.

Proposed improvement:
- Introduce a background overlay and blur.
- Keep the logo fully inside the modal.
- Improve placeholder and password recovery link readability.
- Maintain clear visual states for interactive buttons.

These examples represent the recommendations documented in the supporting improvement tracker. They are proposals and should not be interpreted as approved or implemented changes unless their status confirms that.

## Priority & Status Management

### Priority Classification

- **High:** Blocks or seriously disrupts an important user journey.
- **Medium:** Creates noticeable friction or confusion.
- **Low:** Minor clarity, consistency, or visual polish improvement.

### Finding Classification

- **Bug:** Existing functionality does not work as expected.
- **Improvement:** Existing functionality works but the experience could be clearer, easier, or more efficient.

### Improvement Status

The tracker supports the following statuses:

- Identified
- Under Review
- Awaiting Client Feedback
- Awaiting Designer Feedback
- Agreed
- Ready for Development
- In Progress
- Completed
- Deferred
- Rejected

This separation helps distinguish an initial recommendation from a confirmed product decision.
